## Сравнение и ограничения

- Исходный FPS составил 29.38 / 8.22 / 1.56 для A/B/C. Повторный прогон дал 29.88 / 4.46 / 1.80. В C после изменения наблюдались более высокие задержки ACK, а в B снизился FPS. Устойчивого ускорения эти замеры не подтверждают.
- Рендерер ограничил перестроение объектов изменением данных и разрешений их слоя. Display nodes токенов переиспользуются при перемещениях. Фоновая карта перестраивается при смене сцены, размеров или ассета.
- Перцентили C получены по восьми интервалам кадров. Запланируйте повторы на аппаратном рендерере и профиль React/Pixi для C перед определением лимитов.
- **NOT_MEASURED** для VRAM, долгосрочной утечки памяти, аппаратного FPS, полного сетевого трафика и одновременного рендеринга у всех участников. Два снимка JS heap не позволяют судить об утечке. Отдельный браузерный тест проверяет повторную загрузку ассета после ухода со сцены и возврата.
