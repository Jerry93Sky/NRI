# Trading

В [Master Studio](MASTER_STUDIO.md) можно подготовить торговца и его ассортимент для повторного использования. [Adventure Builder](ADVENTURE_BUILDER.md) связывает доступного торговца с локацией кампании.

**Статус `PLANNED`.**

## Согласованные требования

В качестве ориентира для последовательности взаимодействия используется торговля в Baldur’s Gate 3. Интерфейс и ресурсы EVERDOOR проектируются самостоятельно. Игрок может покупать, продавать, обмениваться и торговаться. Отношение NPC и социальные проверки могут менять условия сделки по правилам кампании. NPC отыгрывает мастер. Игрок может сам открыть торговлю в доступной локации торговца. [Player Tabletop](PLAYER_TABLETOP.md) · [Social Relations](../architecture/SOCIAL_RELATIONS.md)

Merchant Builder помогает мастеру быстро создать торговца. Мастер задаёт атрибуты, встроенный процедурный генератор подбирает ассортимент из доступной библиотеки предметов, мастер может отредактировать результат. Внешний AI для работы генератора не требуется. [Библиотека предметов](INVENTORY_EQUIPMENT.md) · [GM Screen](GM_SCREEN.md)

## Предложения и открытые решения

- Возможные параметры генерации включают специализацию, достаток, тип поселения, регион, допустимую редкость и размер ассортимента. Точный набор предстоит согласовать.
- При открытии торговли предложено учитывать раскрытие торговца этому игроку, доступность взаимодействия и текущие серверные права.
- Продажа услуг NPC отложена. Хранение запасов, денежный лимит торговца и пополнение ассортимента требуют отдельного решения. Связь с экономической симуляцией запланирована на будущее. [Economic Simulation](../architecture/ECONOMIC_SIMULATION.md)

## Требование к сделкам

Сервер проверяет применимые права и условия и применяет обмен предметов, денег и запасов одной атомарной операцией. Это относится и к бартеру. Контракты цен, торга, валют и остатков предстоит определить до разработки.
