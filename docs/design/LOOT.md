# Loot

**Статус `PLANNED`.**

## Согласованные требования

Мастер раскрывает доступную добычу. Предпочтительный режим позволяет игрокам свободно забрать раскрытые предметы. Встроенный процедурный генератор подбирает добычу из доступной библиотеки, после чего мастер может изменить результат. С побеждённого NPC по умолчанию выпадают предметы из его фактического инвентаря. Мастер может изменить состав перед раскрытием.

Деньги автоматически разделяются между участниками. Уникальные артефакты сохраняют идентичность мира кампании при переходе к игроку. Сервер не допускает, чтобы два получателя завладели одним экземпляром добычи. Права проверяются на момент получения. [Предметы и артефакты](INVENTORY_EQUIPMENT.md) · [Игровой стол](PLAYER_TABLETOP.md) · [Панель мастера](GM_SCREEN.md)

## Предложения генератора

Тип противника, регион, сложность, редкость и приблизительная ценность — возможные входные параметры. Алгоритм, точный набор параметров, правила расчёта долей и округление предстоит определить. При выдаче существующего предмета меняется владелец экземпляра, а выдача из шаблона создаёт независимый экземпляр в пределах правил мира.
