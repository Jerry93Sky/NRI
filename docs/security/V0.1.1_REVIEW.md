# V0.1.1 targeted security review

**Status:** `IN_PROGRESS`  
**Review date:** 2026-11-26
**Branch:** `codex/v0-1-foundation-vtt`

This is a targeted engineering review, not an independent security assessment or certification. It records checks actually run so far and the remaining scope.

## Checks and evidence

| Check | Result | Evidence / limits |
|---|---|---|
| Production and full dependency audits | `PASS` after remediation | `corepack pnpm@12.23.0 audit --prod` and `corepack pnpm@12.23.0 audit` now both report `No known vulnerabilities found`. The prior audits identified SEC-001 in `i18next` and SEC-002 in a deprecated `@esbuild-kit/core-utils` dependency path. |
| Session and request boundary code review | `PARTIAL` | Reviewed startup secret validation, cookie settings, request origin checks, authentication rate limits, and Socket.IO origin/session middleware in `apps/server/src/index.ts`. Broader CSRF/deployment proxy validation and secret-free log review remain open. |
| Membership, roles, and media access | `PARTIAL` | Reviewed campaign role lookup, role-change/removal socket-room handling, campaign room joins, pointer room and scene checks, and asset read filtering. Original and thumbnail asset routes share the same campaign role and visible-use checks; isolated smoke covers unreferenced denial and map/token visibility transitions for thumbnails. The suite does not cover every route/event or multi-socket revocation race. |
| Hidden scene-object copy projection | `PASS` for covered paths | Two-context Playwright coverage creates a GM-layer object (the API forces `visible: false`), copies its fields to the player-visible Objects layer, and confirms the copy remains absent from the Player projection. Group-copy checks source versions and creates no partial objects on conflict; Player writes are denied. Other update/delete/reconnect event permutations remain open. |
| GM-only hidden dice results | `PASS` for covered paths | Migration `0016_married_otto_octavius` persists a visibility flag. The server accepts hidden rolls only from Owner/GM members and emits results to the campaign GM room; isolated smoke verifies Player request denial and non-delivery to Players, and the Chromium flow verifies the GM control and recipient filtering. Multi-socket role-revocation permutations remain open. |
| Player freehand drawing ownership | `PASS` for covered paths | The permission defaults off and is managed only by an Owner/GM. Isolated smoke and two-context Playwright cover active-scene/public-layer limits, freehand-only creation, private creator IDs, per-viewer `ownedByMe`, versioned own-stroke edits/deletes, owner-only bulk clear, denial for another Player, and immediate permission revocation. Broader multi-socket update/delete/reconnect permutations remain open. |
| Concurrent token movement | `PASS` for covered conflict paths | Multiplayer smoke and a two-browser Chromium scenario issue simultaneous Owner/GM and token-owner socket moves from one version. Exactly one commits; the stale acknowledgement and Player realtime event match the winner's public coordinates/version. Broader disconnect and race permutations remain open. |
| Persistence and reconnect after API restart | `PASS` for covered paths | CI terminates and relaunches its isolated API process while GM and Player browsers are connected. Both sessions reconnect, remain authenticated, and receive the persisted scene/token state from PostgreSQL. Restart during a database write and broader multi-socket permission-revocation permutations remain open. |
| Campaign-copy authorization and asset isolation | `PARTIAL` | `POST /api/campaigns/:campaignId/duplicate` requires an active Owner/GM membership and rechecks membership in a repeatable-read transaction. Source asset paths are restricted to a single storage-key component, size and SHA-256 are checked, and copied bytes receive new storage keys and campaign-scoped asset rows. The two-context Chromium scenario confirms Player denial, no copied campaign visibility to the Player, a remapped map asset, and distinct scene/token/object IDs. Large-campaign limits are enforced; corrupted-source-file, concurrent-edit, and crash-between-filesystem/transaction coverage remain open. |
| Campaign asset folders | `PARTIAL` | Folder list/create/rename/delete is available only to Owner/GM members; each folder has a campaign foreign key and unique campaign/name index, asset assignment checks same-campaign folder membership, and deletion unassigns assets transactionally without deleting their files. Isolated smoke checks Player denial, duplicate names, cross-campaign assignment rejection, rename, and delete. Chromium checks the folder UI, and campaign-copy coverage checks folder and asset-reference remapping. Rename/revocation concurrency and broader API negative coverage remain open. |
| Upload validation | `PARTIAL` | Signature/header validation plus bounded full decoding using `sharp` allows PNG/JPEG/WebP and rejects unsupported dimensions and malformed pixel streams. A generated valid PNG and truncated IDAT stream pass/fail as expected in unit and isolated API smoke checks. Bounded WebP thumbnails are generated and served with the same asset visibility authorization as originals. Animated WebP is rejected; the wider upload adversarial matrix remains open. |
| Daybreak Defense Factory scan | `NOT RUN` | Required bootstrap returned `access: denied` and the workspace was not eligible. No cloud scan or findings are claimed. |

## Finding registry

| ID | Severity | Finding | Status |
|---|---|---|---|
| SEC-001 | Moderate | `i18next` versions below 26.3.4 allow `deepExtend` to recurse into inherited built-ins, potentially corrupting objects or causing denial of service (GHSA-6jcc-5g8w-32mx). The initial production audit found 25.6.3 in the web dependency tree. | `FIXED`; upgraded the direct web dependency to 26.3.4. A fresh production audit reports no known vulnerabilities. |
| SEC-002 | Moderate | `esbuild` versions through 0.24.2 allow a website to send requests to the development server and read responses (GHSA-67mh-4wv8-2f99). The full audit found 0.18.20 under `drizzle-kit > @esbuild-kit/esm-loader > @esbuild-kit/core-utils`. | `FIXED`; added a scoped pnpm workspace override to `esbuild` 0.25.12 for `@esbuild-kit/core-utils`. Full and production audits now report no known vulnerabilities. |
