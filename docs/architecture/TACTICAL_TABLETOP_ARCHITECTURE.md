# Архитектура Tactical Tabletop

V0.2 развивает существующий сервер как единый процесс Fastify и Socket.IO. PostgreSQL отвечает за сцены, геометрию, версии и историю изученной области. Серверная тактическая проверка получает сцену, текущие разрешения и сохранённую позицию. PixiJS рисует серверную проекцию и локальное превью.

| Компонент | Владелец состояния и граница |
| --- | --- |
| Tactical geometry | Сцена владеет отрезками с типом `WALL`, `DOOR` или `WINDOW`, независимыми флагами `blocksMovement` и `blocksVision`, актуальным положением створки и версией. Публичная форма экспонирует только доступные интерактивные элементы |
| Movement | Общая application-операция для REST и Socket.IO. Читает ревизию геометрии, проверяет пересечение и версию токена в одной согласованной транзакции. Версия карты и изменения всех токенов фиксируются атомарно |
| Visibility | Чистое вычисление по нормализованным отрезкам и источникам. Проектор сервера пересекает результат со стандартными правилами видимости сцены, слоя, объекта, инициативы, токена и изображения |
| Exploration | PostgreSQL хранит версию маски разведки на пару сцена и получатель. Открытые клетки сливаются через объединение. Сброс требует явной команды GM с проверкой версии |
| Renderer | Отдельные Pixi-слои сцены, доступного света, текущей видимости и тумана. Превью GM может показывать режим другого участника, используя соответствующий серверный расчёт |

Сцена получает монотонную ревизию тактики. Ключ кэша включает scene ID, ревизию, идентификатор получателя и набор версий источников. Записи с истёкшей ревизией или отозванной аудиторией освобождаются. Пространственная сетка по прямоугольникам отрезков и источников ограничивает кандидатов. Перестройка выполняется по изменённым ячейкам, а при смене сцены разрешается полный снимок.

Расширения обращаются через серверные операции проверки перемещения, запроса доступных целей и изменения способности видения. Обмен использует campaign ID, scene ID, entity ID и численные координаты. Правила конкретной системы передаются опционально через параметры способности. Хранилище тактики и протокол сохраняют независимость от игровых систем.
