# Модель видимости

## Геометрия

Координаты сцены квантуются до фиксированной точности. Проверки пересечения, совмещения концов отрезков и касания проходят через одну библиотеку чистых операций. При равенстве углов или расстояний порядок определяется концами отрезков и ID. Набор тестов включает коллинеарность, нулевую длину, закрытый угол, совпавшие двери и вход зрения на границу карты.

| Подход | Применение |
| --- | --- |
| Угловой обход видимых концов отрезков | Выбран для непрерывной LOS. Сохраняет узкие проходы и точные границы при масштабировании. Использует пространственный индекс для кандидатов и детерминированный порядок событий |
| Клеточная трассировка лучей | Подходит для сохранённой изученной маски и быстрой проверки прямоугольника-кандидата. На грубой сетке даёт ступенчатую границу |
| Равномерные лучи или GPU-маска | Подходят для локального визуального эффекта. Между лучами теряются препятствия, а результат GPU зависит от параметров рендера |

Вклад источника видения — многоугольник радиуса и углового поля, ограниченный ближайшими пересечениями. Сервер объединяет источники, которыми владеет текущий игрок. Объект попадает в проекцию после проверки уровня доступа и пересечения доступной области. Для крупных объектов политика раскрытия зависит от категории и проверяется отдельно.

## Состояние и аудитория

Текущая видимость сбрасывается при переподключении и строится по снимку. Изученная область хранит геометрические клетки без содержимого скрытых токенов и объектов. Статические карты с нераскрываемым содержимым доставляются фрагментами с серверным ACL. Переходный GM-режим может использовать карты, заранее подготовленные без секретного содержимого.

В Player-ответ входят разрешённый фрагмент и события входа, обновления и удаления доступных сущностей. Кэш, ассеты, миниатюры, инициативные записи и снапшоты используют тот же контекст аудитории. Силуэты закрытых областей сами могут раскрывать препятствие. Для сценариев с секретной стеной ведущий выбирает границу раскрытия крупнее геометрии препятствия. Точные сегменты и метаданные выдаются по правилам обнаружения.
