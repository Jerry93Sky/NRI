# Модель освещения

Предлагаемый источник света имеет координаты сцены либо привязку к токену, радиус, угол, интенсивность, оттенок, флаг активности и версию. В V0.2 свет является графическим эффектом. Он ограничен препятствиями и уже разрешённой областью обзора. Интенсивность в Pixi влияет на изображение. Правила игровой темноты и специальные пороги восприятия можно добавить позже через серверную модель видимости.

| Подход | Оценка |
| --- | --- |
| Серверная полигональная отсечка и клиентское смешивание | Выбран. Общая с LOS геометрия повторяема и позволяет фильтровать проекцию на сервере. Клиенту передаются разрешённые области и видимые параметры |
| Клеточное поле света на сервере | Уместно для тестируемого правила порога и повторного использования изученной сетки. Грубая детализация создаёт видимую ступенчатость |
| Динамические тени целиком в GPU | Уместны для визуальной обработки доступной области. Движок требует геометрии, которую серверу пришлось бы раскрывать для расчёта |

Сервер переиспользует LOS-индекс. Переоценка источника происходит при его перемещении, изменении угла или изменении пересекающегося препятствия. Кэш хранит базовые области источников по ревизии геометрии. Проекция объединяет только видимые вклады для конкретного получателя. Фрагменты за пределами доступной карты и невидимые параметры источников отсутствуют в трафике.

Лимиты источников, частоты движений и площади динамического слоя определяются отдельными измерениями поверх [V0.1.1 baseline](../performance/BASELINE.md). Настраиваемые пороги относятся к будущим правилам сцены. [Дизайн редактора](../design/MAP_SCENE_EDITOR.md)
