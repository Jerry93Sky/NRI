# V0.2 — Tactical Tabletop

Статус `IN_PROGRESS`. Владелец разрешил разработку V0.2 на рабочей ветке параллельно с оставшимися ручными проверками V0.1.1. Критерии выпуска сохраняются. [Открытые проверки V0.1.1](V0.1.1_FINAL_READINESS.md) · [Профили производительности](../performance/BASELINE.md)

| Область | Приёмка V0.2 |
| --- | --- |
| Стены, двери, окна | Ведущий редактирует версионированные отрезки. Флаги движения и видимости независимы. Дверь меняет состояние через авторизованную команду |
| Движение | Сервер проверяет весь отрезок движения от сохранённой позиции. Групповое действие отклоняется целиком при конфликте или непроходимом сегменте |
| Видимость | Для каждой сессии публикуется проекция по видению доступных пользователю токенов. Изменение владельца, роли или активной сцены меняет доступ |
| Туман и изученная область | Текущая видимость временная. Исследованная область сохраняется по сцене и получателю. Скрытые изменения за пределами текущей видимости отсутствуют в Player-проекции |
| Освещение | Радиус, приоритет, оттенок и яркость задаются ведущим. Препятствия ограничивают графический эффект. Эффект освещения не расширяет серверный обзор и не раскрывает объекты |
| Управление GM | Привилегированный просмотр служит подготовке сцены. Выбор режима просмотра не изменяет разрешения Player |

Этап PR 1 вводит геометрию, версионирование и редактор ведущего. Последующие этапы добавляют проверку пути, проекции, туман и графический свет в заданном порядке. Точки расширения описаны в [архитектуре](../architecture/TACTICAL_TABLETOP_ARCHITECTURE.md) и [дизайне редактора](../design/MAP_SCENE_EDITOR.md). Character Studio, Universal Rules Engine, сложная геометрия на этажах и расширенные правила освещения остаются за пределами релиза.
