# V0.2 — Tactical Tabletop

Статус `NOT_STARTED`. План зависит от технического закрытия V0.1.1 и измерений в [BASELINE.md](../performance/BASELINE.md).

| Область | Приёмка V0.2 |
| --- | --- |
| Стены, двери, окна | Ведущий редактирует версионированные отрезки. Флаги движения и видимости независимы. Дверь меняет состояние через авторизованную команду |
| Движение | Сервер проверяет весь отрезок движения от сохранённой позиции. Групповое действие отклоняется целиком при конфликте или непроходимом сегменте |
| Видимость | Для каждой сессии публикуется проекция по видению доступных пользователю токенов. Изменение владельца, роли или активной сцены меняет доступ |
| Туман и изученная область | Текущая видимость временная. Исследованная область сохраняется по сцене и получателю. Скрытые изменения за пределами текущей видимости отсутствуют в Player-проекции |
| Освещение | Радиус, приоритет, оттенок и яркость задаются ведущим. Свет ограничен препятствиями. Сервер выдаёт только доступные эффекты и геометрию |
| Управление GM | Привилегированный просмотр служит подготовке сцены. Выбор режима просмотра не изменяет разрешения Player |

Точки расширения описаны в [архитектуре](../architecture/TACTICAL_TABLETOP_ARCHITECTURE.md). Character Studio, Universal Rules Engine, сложная геометрия на этажах и произвольная физическая модель света остаются за пределами релиза.
