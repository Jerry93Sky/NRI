## Что стоит сохранить

- PostgreSQL уже обеспечивает внешние ключи, индексы по основным границам и уникальность активной сцены. CAS по версиям и транзакции используются при части групповых действий.
- Storm of updates следует сначала оценить на существующих снимках и событиях. Поток восстановления после перезапуска уже покрыт исходным CI. Потребность в event cursor и transactional outbox отдельно не доказана.
- В проекте уже есть Amber Crossing, подтверждение авторства материалов, API и браузерные проверки, приватные проекции сцен и ассетов и освобождение неиспользуемых текстур. Отчёт о релизе хранит исторические скриншоты. Они не заменяют сравнение актуальных GM/Player-состояний на трёх разрешениях.
