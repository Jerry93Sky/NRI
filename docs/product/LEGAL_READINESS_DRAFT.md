# Юридическая готовность EVERDOOR

**Статус `DISCUSSION_DRAFT`.** Рабочий список вопросов для обсуждения с профильным специалистом перед коммерческим запуском.

| Тема | Открытые вопросы |
| --- | --- |
| Бизнес и налоги | Юрисдикция регистрации, правовая форма, налоговое резидентство владельца |
| Название и код | Проверка и возможная регистрация знака EVERDOOR, права на исходный код и вклады, публичность репозитория и будущая лицензия проекта |
| Зависимости и правила | Лицензии библиотек и игровых систем, права на переводы, изображения, материалы и распространение пакетов правил |
| Пользовательские материалы | Права на загрузку, использование и удаление контента, модерация, работа с жалобами |
| Персональные данные | Собираемые данные, цели и сроки хранения, региональное размещение и требования для выбранных рынков |
| Платежи и документы | Доступные провайдеры, валюты, пользовательское соглашение и коммерческая оферта |
| Marketplace | Ответственность платформы и продавцов, роль платёжного посредника, правила для авторов и ведущих платных сессий |

Первый рынок и дальнейший международный охват описаны отдельно. Перед решениями о публичном каталоге проверяются права и условия каждой лицензии. [Коммерческая стратегия](COMMERCIAL_STRATEGY_DRAFT.md) · [Лицензирование игровых систем](RULESET_LICENSING_STRATEGY.md)
