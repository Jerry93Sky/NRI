# NRI Platform

NRI Platform — универсальная виртуальная игровая площадка для настольных ролевых игр. Ядро не зависит от правил конкретной НРИ; ведущий управляет кампанией, сценами, токенами и доступом игроков.

## Статус

- **Версия:** V0.1.1 — Tabletop Foundation Completion & Playability
- **Реализация:** IN_PROGRESS
- **Автоматические проверки:** AUTOMATED_TESTS_PASSED для имеющихся локальных проверок
- **Приёмка владельцем:** IN_PROGRESS — технические ворота V0.1.1 ещё открыты

Рабочая версия API и интерфейса запущена локально; `Amber Crossing` доступна для ручной проверки. V0.1.1 остаётся в разработке: слои объектов, ручная проверка калибровки на карте, расширенные токены, библиотека ресурсов, инструменты стола, Playwright, backup/restore и нагрузочные проверки не завершены. См. [объём работ](docs/releases/V0.1.1_SCOPE.md) и [отчёт V0.1.1](docs/releases/V0.1.1_ACCEPTANCE_REPORT.md).

## Реализовано

- Регистрация, вход, выход, сессии и ограничение частоты попыток.
- Кампании, роли Owner/GM/Player, приглашения с ограничением использований и отзывом, архивирование и восстановление.
- Сцены с активной игровой версией и черновиками ведущего, переименованием, дублированием, архивированием/восстановлением, порядком и настраиваемой сеткой/камерой; игрокам выдаётся только активная сцена.
- Токены, назначения владельцев, серверная авторизация перемещения и синхронизация Socket.IO.
- Публичный и приватный чат, серверные броски кубиков, трекер инициативы с фильтрацией скрытых ходов.
- Русский и английский интерфейс, локальная разработка, Docker Compose, миграции PostgreSQL и CI workflow.

## Ограничения V0.1.1

- Слои и произвольные объекты сцены, расширенная карточка токена и undo/redo ещё не реализованы. Калибровка сетки с предпросмотром размера и смещений добавлена; проверка на карте ожидает сцену с загруженной картой.
- Карты загружаются как PNG/JPEG/WebP до 12 MB; локальное хранилище не проверяет декодирование и пределы размеров изображения.
- Нет автоматизированного Playwright набора, отдельного восстановительного теста из резервной копии или измерений производительности. Проверены package-local Vitest suites и интеграционный API/Socket.IO smoke на PostgreSQL.
- Нет полноценной редакции слоёв/объектов, экспорта кампании и продакшен-деплоя. GitHub Actions прошёл на рабочей ветке.
- Библиотека ресурсов и дополнительные инструменты стола не завершены; полный аудит безопасности и ручная приёмка владельцем ожидаются.

## Стек

React, TypeScript, Vite, PixiJS, Zustand, i18next; Node.js 24.13, Fastify, Socket.IO, PostgreSQL 16, Drizzle, Zod, pnpm workspaces, Docker Compose, Vitest, GitHub Actions.

## Запуск и проверки

См. [инструкцию локального запуска](docs/development/LOCAL_SETUP.md). Основные команды:

```powershell
corepack pnpm@12.23.0 install --frozen-lockfile
docker compose up -d db
corepack pnpm@12.23.0 db:migrate
corepack pnpm@12.23.0 dev
```

В другом окне:

```powershell
corepack pnpm@12.23.0 build
corepack pnpm@12.23.0 typecheck
corepack pnpm@12.23.0 test
```

Интеграционный тест нескольких клиентов запускается по инструкции в [отчёте приёмки](docs/releases/V0.1_ACCEPTANCE_REPORT.md). Не публикуйте `.env`, пользовательские данные или загруженные карты.
