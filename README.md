# NRI Platform

NRI Platform — универсальная виртуальная игровая площадка для настольных ролевых игр. Ядро не зависит от правил конкретной НРИ; ведущий управляет кампанией, сценами, токенами и доступом игроков.

## Статус

- **Версия:** V0.1.1 — Tabletop Foundation Completion & Playability
- **Реализация:** IN_PROGRESS
- **Автоматические проверки:** AUTOMATED_TESTS_PASSED для имеющихся локальных проверок
- **Приёмка владельцем:** IN_PROGRESS — технические ворота V0.1.1 ещё открыты

Рабочая версия API и интерфейса запущена локально; `Amber Crossing` доступна для ручной проверки. Доступны базовая панель слоёв, изображения и текстовые объекты сцены, временная линейка с несколькими сегментами и единицами сцены, сочетания R/F/P/Escape для линейки/вписывания/указателя/сброса, временный общий указатель, инструменты фигур, свойства внешнего вида и видимости токенов, два приватно фильтруемых трека ресурсов, заметки ведущего/владельца, изображения токенов, восстановление удалённых токенов и атомарное групповое перемещение, скрытие и блокировка до 50 токенов. Вставка и отображение изображений/текста реализованы, но ещё не приняты в браузере. Категорийная библиотека изображений поддерживает пакетную загрузку, поиск, ссылки использования, размер хранилища и удаление только неиспользуемых файлов. Проверка на карте, буфер обмена/undo, полноценное редактирование объектов, миниатюры и папки библиотеки, права рисования, Playwright и нагрузочные проверки ещё открыты. Изолированное восстановление резервной копии пройдено; согласованный maintenance drill остаётся открытым. См. [объём работ](docs/releases/V0.1.1_SCOPE.md) и [отчёт V0.1.1](docs/releases/V0.1.1_ACCEPTANCE_REPORT.md).

## Реализовано

- Регистрация, вход, выход, сессии и ограничение частоты попыток.
- Кампании, роли Owner/GM/Player, приглашения с ограничением использований и отзывом, архивирование и восстановление.
- Сцены с активной игровой версией и черновиками ведущего, переименованием, дублированием, архивированием/восстановлением, порядком и настраиваемой сеткой/камерой; игрокам выдаётся только активная сцена.
- Токены, назначения владельцев и серверная синхронизация перемещения. Ведущий может менять внешний вид и видимость токена, редактировать отдельные заметки ведущего и владельца, а также настраивать два универсальных трека с названием, текущим и максимальным значением и видимостью для игроков. Заметка ведущего доступна только ведущим, заметка владельца — ведущим и назначенному владельцу. Игроки видят только опубликованные треки и могут менять значения лишь у своих токенов; сервер проверяет границы и версии. Для слоёв доступны выбор, изменение порядка, видимость и блокировка; ведущий может создавать изображения из библиотеки, текстовые объекты, линии, рисунки от руки, прямоугольники и эллипсы, а также перетаскивать или менять размер объектов на активном слое. Отображение и изменение текста объектов реализованы, но ещё не проверены в браузере. Изображения токенов, восстановление удалённых токенов и атомарные групповые перемещение/блокировка/видимость до 50 токенов реализованы; копирование через буфер ещё не реализовано; история отмены пока ограничена групповыми перемещениями.
- Публичный и приватный чат, серверные броски кубиков, трекер инициативы с фильтрацией скрытых ходов.
- Русский и английский интерфейс, локальная разработка, Docker Compose, миграции PostgreSQL и CI workflow.

## Ограничения V0.1.1

- Полноценное редактирование слоёв и объектов, групповые операции и undo/redo ещё не реализованы. Калибровка сетки с предпросмотром размера и смещений добавлена; проверка на карте ожидает сцену с загруженной картой.
- Группы можно выбирать в панели свойств и атомарно перемещать перетаскиванием одного выбранного токена; буфер обмена отсутствует; undo/redo пока ограничены групповыми перемещениями. Изображения загружаются как PNG/JPEG/WebP до 12 MB; проверяются сигнатура, заголовки и декодируемый размер до 64 MiB, но полное декодирование файла не проверяется. Миниатюры и папки ещё не реализованы.
- Нет автоматизированного Playwright набора, автоматизации резервного копирования или измерений производительности. Изолированное восстановление `nri_test` проверено с совпадением данных и SHA-256 ссылок ассетов; production-like maintenance drill ожидает проверки.
- Нет полноценного редактора слоёв/объектов, экспорта кампании и продакшен-деплоя. GitHub Actions PR run #68 прошёл на коммите `57d0b6d`; новые локальные изменения документации ещё ожидают CI.
- Библиотека ресурсов и дополнительные инструменты стола не завершены; полный аудит безопасности и ручная приёмка владельцем ожидаются.

## Запуск и проверки

См. [инструкцию локального запуска](docs/development/LOCAL_SETUP.md). Основные команды:

```powershell
corepack pnpm@12.23.0 install --frozen-lockfile
docker compose up -d db
corepack pnpm@12.23.0 db:migrate
corepack pnpm@12.23.0 dev
```

В другом окне:

```powershell
corepack pnpm@12.23.0 build
corepack pnpm@12.23.0 typecheck
corepack pnpm@12.23.0 test
```

Интеграционный тест нескольких клиентов запускается по инструкции в [отчёте приёмки](docs/releases/V0.1_ACCEPTANCE_REPORT.md). Не публикуйте `.env`, пользовательские данные или загруженные карты.
