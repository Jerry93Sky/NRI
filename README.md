# NRI Platform

NRI Platform — универсальная виртуальная игровая площадка для настольных ролевых игр. Ядро не зависит от правил конкретной НРИ; ведущий управляет кампанией, сценами, токенами и доступом игроков.

## Статус

- **Версия:** V0.1.1 — Tabletop Foundation Completion & Playability
- **Реализация:** IN_PROGRESS
- **Автоматические проверки:** AUTOMATED_TESTS_PASSED для коммита `bc26408` (GitHub Actions #184)
- **Приёмка владельцем:** IN_PROGRESS — технические ворота V0.1.1 ещё открыты

Локальные API и интерфейс доступны для демонстрации; отдельная кампания `Amber Crossing: The Lantern Vault` подготовлена для ручной проверки. Реализованы сцены с черновиками ведущего и активной сценой игроков, слои и объекты, настройка и калибровка сетки, токены с приватными ресурсами и заметками, библиотека изображений с папками, групповые операции, линейка, указатель и инструменты рисования. Поддерживаются публичный/приватный чат, публичные и скрытые броски, инициатива, переподключение и версионированные конфликты движения токенов. Правая панель, полноэкранный режим и темы имеют автоматизированное браузерное покрытие; Chromium проверяет раскладку при 1366×768, 1920×1080 и 2560×1440. GitHub Actions #184 прошёл на коммите `bc26408`, включая удаление участника с двумя активными Player-сессиями: обе получили уведомление об отзыве, перестали получать игровые события, а запись была запрещена. Это автоматические проверки, не ручная приёмка владельцем. Открыты ручная проверка полной демо-сессии и калибровки, часть редактирования объектов и Undo/Redo, расширенный security review, согласованный maintenance-window backup/restore, расписание хранения и реальные измерения производительности. Подробности и ограничения — в [объёме работ](docs/releases/V0.1.1_SCOPE.md) и [отчёте V0.1.1](docs/releases/V0.1.1_ACCEPTANCE_REPORT.md).

## Реализовано

Демо «Amber Crossing: The Lantern Vault» можно подготовить командой `corepack pnpm@12.23.0 db:seed:playable-amber`: она создаёт отдельную кампанию, три сцены и оригинальные процедурные карты и портреты, не меняя исходную `Amber Crossing`. В списке кампаний Owner/GM может создать независимую копию с отдельными ID сцен, слоёв, объектов, токенов, ассетов и файлов. Руководство по сессии и реестр ассетов: [AMBER_CROSSING_PLAY_GUIDE.md](docs/demo/AMBER_CROSSING_PLAY_GUIDE.md) и [ASSET_PROVENANCE.md](docs/demo/ASSET_PROVENANCE.md). Копирование проверено отдельным двухконтекстным Playwright-сценарием; полный ручной просмотр кампании ещё открыт.

- Регистрация, вход, выход, сессии и ограничение частоты попыток.
- Кампании, роли Owner/GM/Player, приглашения с ограничением использований и отзывом, архивирование и восстановление.
- No-overwrite-команды резервной копии PostgreSQL и медиа с проверкой SHA-256-манифеста (`db:backup`, `db:backup:verify`); согласованный maintenance drill и расписание хранения остаются открытыми.
- Библиотека кампании включает папки с фильтрацией, перемещением ресурсов, переименованием и удалением; при удалении папки файлы остаются в библиотеке, а копирование кампании переназначает ID папок и ресурсов.
- Сцены с активной игровой версией и черновиками ведущего, переименованием, дублированием, архивированием/восстановлением, порядком и настраиваемой сеткой/камерой; игрокам выдаётся только активная сцена.
- Токены, назначения владельцев и серверная синхронизация перемещения. Перетаскивание переводит экранные смещения в координаты сцены при текущем масштабе; изолированный Chromium-сценарий проверяет перемещение ведущим на одну клетку и обновление холста игрока. При конфликте версий сервер возвращает авторизованному клиенту актуальный отфильтрованный снимок токена. Ведущий может менять внешний вид и видимость токена, редактировать отдельные заметки ведущего и владельца, а также настраивать два универсальных трека с названием, текущим и максимальным значением и видимостью для игроков. Заметка ведущего доступна только ведущим, заметка владельца — ведущим и назначенному владельцу. Игроки видят только опубликованные треки и могут менять значения лишь у своих токенов; сервер проверяет границы и версии. Для слоёв доступны выбор, изменение порядка, видимость и блокировка; ведущий может создавать изображения из библиотеки, текстовые объекты, линии, рисунки от руки, прямоугольники и эллипсы, а также перетаскивать или менять размер объектов на активном слое. Отображение и изменение текста объектов реализованы, но ещё не проверены в браузере. Изображения токенов, восстановление удалённых токенов и атомарные групповые перемещение/блокировка/видимость и копирование до 50 токенов реализованы; копии создаются с новыми ID и очищенными полями владельца; для одного объекта сцены доступно in-app копирование/вставка; история отмены пока ограничена групповыми перемещениями.
- Публичный и приватный чат, публичные броски и скрытые броски, которые видны только ведущим, серверные кубики и трекер инициативы с фильтрацией скрытых ходов.
- Автоматизированный Chromium-сценарий проверяет перетаскивание токена на одну клетку при текущем масштабе с обновлением у игрока, а также переподключение Socket.IO после офлайн/онлайн и повторную доставку общего чата.
- Русский и английский интерфейс, локальная разработка, Docker Compose, миграции PostgreSQL и CI workflow.

## Ограничения V0.1.1

- Undo/Redo ограничены перемещениями; полная история редактирования объектов и свойств ещё не реализована. Часть жестов редактирования фигур и текста остаётся без ручной проверки.
- Браузерный конфликт двух авторизованных перемещений, восстановление GM/Player после перезапуска API и удаление участника с двумя активными сокетами проверены; расширенная матрица отзыва ролей и прав ещё открыта.
- Локальный backup/restore и проверка манифеста прошли на изолированных базах. Согласованное окно обслуживания с остановкой записей, расписание хранения и проверка восстановления всех требуемых данных остаются открытыми.
- Профиль трёх нагрузочных сцен и шести игроков, FPS, задержек, памяти, сервера и текстурных лимитов оборудования ещё не снят.
- Ручная проверка калибровки на карте и полной демо-сессии остаётся открытой. Расширенный security review не является независимой сертификацией.

## Запуск и проверки

См. [инструкцию локального запуска](docs/development/LOCAL_SETUP.md). Основные команды:

```powershell
corepack pnpm@12.23.0 install --frozen-lockfile
docker compose up -d db
corepack pnpm@12.23.0 db:migrate
corepack pnpm@12.23.0 dev
```

В другом окне:

```powershell
corepack pnpm@12.23.0 build
corepack pnpm@12.23.0 typecheck
corepack pnpm@12.23.0 test
```

Интеграционный тест нескольких клиентов запускается по инструкции в [отчёте приёмки](docs/releases/V0.1_ACCEPTANCE_REPORT.md). Не публикуйте `.env`, пользовательские данные или загруженные карты.
